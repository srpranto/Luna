# Luna 🌙

**[🌐 Live Demo → luna-ggwp.vercel.app](https://luna-ggwp.vercel.app)**

A quiet late night place for honest, anonymous conversations with strangers under the moon.

Luna is an ephemeral, anonymous web application and PWA made for those late hours when you just want to talk to someone without having to explain who you are. It connects strangers in private, distraction free rooms with end to end encryption, quiet ambient soundscapes, and an anonymous letter drop called The Void.

## ✨ Features

- **Anonymous Stranger Matching**: Connect one on one with strangers without creating an account or sharing an email address or phone number.
- **Client Side Session Security**: Messages are handled with ephemeral encryption primitives through the Web Crypto API, so the conversations do not need to become permanent.
- **Interactive Ambient Soundscapes**: Listen to quiet, procedurally created environments like Rain on Glass, Stargazer, Midnight Vinyl, and Deep Orbit through the Web Audio API.
- **The Void Letters**: Leave a thought, an unsaid word, or something you could not tell anyone. You can also read letters left behind by other strangers.
- **Installable PWA**: Luna can be installed on mobile or desktop with an offline ready shell, custom manifest, and service worker caching.
- **Celestial Dark Interface**: The interface is built around a calm midnight feeling, with a reactive canvas starfield and small, smooth interactions.
- **In Memory & Embedded Persistence**: Uses ElectricSQL PGLite for lightweight embedded database operations without needing a separate database service.

## 🔒 Privacy & Safety

- No third party trackers, analytics, or behavioral cookies.
- No permanent user identities, tracking profiles, or social graph connections.
- Ephemeral chat sessions are cleared when users disconnect or leave the room.
